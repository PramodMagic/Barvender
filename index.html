FAQ

Is my data uploaded anywhere?

No. Your Excel file is read and turned into labels inside your browser, and is gone when you close or refresh the page.

Which printers work?

Any printer that can print from a browser, including thermal label printers. Set your paper size and print with margins set to None and scale 100%.

Can I print 2 labels side by side on a roll?

Yes. Choose per-paper mode, set the paper width, label size and labels per row.
